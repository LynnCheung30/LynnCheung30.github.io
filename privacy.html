Privacy policy: hongguo rclone

hongguo rclone is a personal tool used only by its owner.

  • It requests only the drive.file Google Drive scope, so it can see and change only the files it uploads itself. It cannot read any other file in the Google Drive.
  • It uploads the owner's own research data files to the owner's own Google Drive. Nothing is sent to anyone else.
  • It collects no personal data from any other person, uses no analytics, and shares nothing with third parties.
  • Access can be revoked at any time at myaccount.google.com/permissions.
